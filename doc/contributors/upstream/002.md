# Lövetest's `getMeshCullMode` test leaves the cull mode at `back`

At the pinned LÖVE commit, `b7daef0f7`. Written as the report we would file; LÖVE accepts none made with generative AI (AGENTS.md, "Reporting upstream"), so it stays here.

The test sets the mode and does not restore it (`testing/tests/graphics.lua`). Lövetest runs its tests in alphabetical order, so the tests after it that draw meshes happen to run with the mode `drawInstanced` needs. Run in any other order, `drawInstanced` draws nothing. Reported by Lota's slice 6 work; Lota's test setup resets the mode.

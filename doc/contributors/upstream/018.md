# On Android, love.run reads the frame's dt before love.graphics.clear, so dt alternates

At the pinned LÖVE commit, `b7daef0f7`. Written as the report we would file; LÖVE accepts none made with generative AI (AGENTS.md, "Reporting upstream"), so it stays here. It needs no code change in Lota.

On Android, a game that draws every frame sees a `dt` that alternates between a short and a long value, though the display shows a new frame every 16.7 milliseconds. A game that moves by `dt` stutters.

## What happens

`love.run` takes the frame's time before it clears the screen (`src/modules/love/callbacks.lua`, lines 187-201):

<!-- SPDX-SnippetBegin -->
<!--
  SPDX-FileCopyrightText: 2006-2026 LOVE Development Team
  SPDX-License-Identifier: Zlib
-->
```lua
local dt = love.timer and love.timer.step() or 0
if love.update then love.update(dt) end
if love.graphics and love.graphics.isActive() then
	love.graphics.origin()
	love.graphics.clear(love.graphics.getBackgroundColor())
	if love.draw then love.draw() end
	love.graphics.present()
end
```
<!-- SPDX-SnippetEnd -->

On Android, `love.graphics.clear` blocks 6 to 11 milliseconds, waiting for a free buffer. The wait falls after `love.timer.step()`, so it counts toward the next frame's `dt`, not this one's. So `dt` alternates, for example 7.5, 25, 7.5 milliseconds, though the display shows a frame every 16.7.

## To reproduce

A game that records `dt` each frame, run on a OnePlus Nord N30 5G (Android 14, Adreno 619, OpenGL ES) for 300 frames. The `dt` values go 7.5, 25, 7.5, 25 milliseconds. In 300 frames, 52 to 67 ran over 20 milliseconds, across runs.

Moving `love.timer.step()` after `love.graphics.clear` in a copy of `love.run` gives 0 to 3 of 300 over 20 milliseconds. The wait for the buffer then falls before the step, so each `dt` measures a whole display frame.

## What Lota does

Nothing. Lota keeps LÖVE's order, as a faithful port (`Lota.run`): a game that moves by `dt` behaves in Lota as it does in LÖVE. A game may replace `Lota.run`, or time its own frames, as a LÖVE game may replace `love.run`.

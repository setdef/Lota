# `Mesh:getAttachedAttributes` returns an empty table

At the pinned LÖVE commit, `b7daef0f7`. Written as the report we would file; LÖVE accepts none made with generative AI (AGENTS.md, "Reporting upstream"), so it stays here.

Confirmed by reading `wrap_Mesh.cpp` (line 412): it writes each attribute into the table it is building with `lua_rawseti(L, -1, ...)`, which writes it into itself, so the function returns an empty table at the pinned commit. Lota binds `Mesh#attached_attributes` as LÖVE has it, returning an empty Array, and documents it.

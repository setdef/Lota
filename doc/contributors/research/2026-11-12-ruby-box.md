# Why Ruby Keeps a Dropped `Ruby::Box` Alive

A restart could run a game inside a `Ruby::Box` and drop the box, as LÖVE closes a Lua state. Lota does not, because Ruby never frees such a box ([game.md](../design/game.md), "Restarting"). This note records what that rests on, so a later Ruby can be checked against it.

## What was measured

Before Lota chose to restart by `exec`, on 2026-11-02, a spike restarted a game in a box, dropped on each restart. On Ruby 4.0.7 and 4.0.9, five restarts left five copies of the engine alive, with their audio devices and threads, about 36 MB each. The box also loaded its own copy of Lota's extension from a temporary directory, broke `$stdout` redirection, and could not keep the window.

Checked again by 2026-11-12 on Ruby 4.1.0-preview1 (`2d08b5f42f`), five dropped boxes that each defined a class were all still alive after full collections, as on 4.0.7. Ruby 4.1's `NEWS.md` lists no change to boxes.

## Why

A study of Ruby's master branch on 2026-11-12 (`acc624e47b`) found two separate causes. Neither is Bug #22403, which is about a box keeping its own classes alive.

- A box that sets a constant on `Object`, as `class Foo` does, gets its own copy of `Object`'s class data, which `Object` marks strongly (`class.c`, lines 450–459; `gc.c`, line 3917). The constant's class marks its box (`gc.c`, lines 3918–3920), so the box is never unreachable. A fix would make those copies weak: roughly 200 to 400 lines across `gc.c`, `box.c`, `class.c`, and `internal/class.h`, and risky.
- A class defined from C is pinned as a permanent root (`class.c`, lines 1606–1610 and 1680–1692), and Rice defines every Lota class that way. Freeing a box that loaded an extension needs pins scoped to the box, and the extension's copy unloaded early: a change to Ruby's design, not a bug fix.

With RubyGems loaded, as it is by default, even an empty box is never freed, since each box loads RubyGems' prelude (`box.c`, lines 436–441).

A patched Ruby, carried by Fledge, was judged impractical. A report of the first cause to Ruby, raising the second, would start the way back to boxes; none has been filed.

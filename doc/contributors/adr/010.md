# ADR 010: Ship Games Through Fledge's Embedded Ruby

## Status

Accepted

## Date

2026-11-02, replacing a launcher of Lota's own decided on 2026-10-24

## Context and Problem

A player of a fused LÖVE game double-clicks an app and it runs, with nothing to install. A Lota game needs a Ruby interpreter, the standard library, its gems, Lota's native extension, and LÖVE's engine, and almost no player has Ruby. How does a Lota game reach a player looking exactly like a fused LÖVE game?

## Decision Drivers

- The player installs nothing and sees an ordinary app.
- Ruby runs on the process's main thread, as the engine needs, with YJIT.
- The app controls its own layout and code signing on macOS.
- Nothing on the player's machine changes how the game runs.

## Considered Options

1. Fledge, the maintainer's packaging tool for Ruby apps, which embeds CRuby in a launcher and publishes a runtime for each platform.
2. A launcher and runtimes of Lota's own, built the same way.
3. A single-file packager such as Tebako or OCRAN.

## Decision Outcome

Chosen: option 1. A spike showed the core of option 2 works: a small C launcher statically linking Ruby, running game code on the main thread with YJIT, and passing strict code-signature checks. Fledge then did the same for every Ruby app. Two Lota games built with it ran with no Ruby on the player's path, on the main thread, with YJIT, signed ad hoc and with the hardened runtime. So Lota has no reason to build its own. Option 3 was built for command-line tools: it unpacks to a temporary directory or mounts a virtual filesystem on every launch, and controls less of a macOS app's layout and signing.

### Consequences

- Good, because Lota writes a Fledge project and builds it with `lota fuse`, rather than maintaining a launcher and runtimes.
- Good, because Lota's gem needs nothing special: Fledge copies a game and the gems its lockfile names into its runtime.
- Bad, because Lota publishes a precompiled gem per platform, matched to Fledge's Ruby, and a new Fledge Ruby needs a matching Lota gem first.
- Bad, because Fledge builds an app only on its own platform, so a developer builds on each platform they ship for.
- Bad, because a fused game is larger than a fused LÖVE game, about 93 MB unpacked on macOS.

== Make 2D Games in Ruby

Lota is an independent project, not made, endorsed, or supported by the
LÖVE Development Team. It builds a modified version of LÖVE's C++ engine
and hands control to Ruby instead of Lua, so a game written with it
behaves as the same game written in LÖVE.

== Install

Lota runs with Ruby 4.0 on Apple Silicon Macs, on Linux with glibc
2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36, and their successors)
on x86_64 or arm64, and on Windows with RubyInstaller's Ruby on x64 or
ARM64. Its gem comes compiled for each, with the parts of LÖVE's engine
it loads, so installing it builds nothing:

  gem install lota
  lota run path/to/game
  lota fuse path/to/game

The last builds the game, with Fledge, into an app for this computer's
platform that a player runs without Ruby, with the gems its Gemfile.lock
locks; it needs Git and the network, and a C compiler for a gem whose
extension compiles.

On Linux, a game needs a desktop with X11 or Wayland and OpenGL, as a
LÖVE game does. The Windows gems are new: their continuous integration
runs a game without a window, so a game that draws is not yet tested
there.

On another platform or Ruby, such as Alpine Linux, whose C library is
musl, RubyGems picks Lota's source gem, which stops and says so: Lota
has no build for those yet.

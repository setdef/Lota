== Make 2D Games in Ruby

Lota is a Ruby gem for making 2D games. It builds a modified version of
the C++ engine LÖVE games run on, and runs your game's Ruby on it
instead of Lua, so a game written with it behaves as the same game
written in LÖVE. It keeps LÖVE's modules and functions, renamed by fixed
rules: love.graphics.rectangle("fill", 10, 10, 50, 50) becomes
Lota::Graphics.rectangle(:fill, 10, 10, 50, 50).

Lota is an independent project, not made, endorsed, or supported by the
LÖVE Development Team.

== Install

Lota runs with Ruby 4.0 on Apple Silicon Macs, on Linux with glibc
2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36, and their successors)
on x86_64 or arm64, and on Windows with RubyInstaller's Ruby on x64 or
ARM64. Lota is not on RubyGems.org: each GitHub release at
https://github.com/setdef/Lota/releases carries a precompiled gem for
each platform, with the parts of LÖVE's engine it loads, so installing
it builds nothing:

  gem install --local lota-VERSION-PLATFORM.gem
  lota run path/to/game
  lota fuse path/to/game

The last builds the game, with Fledge, into an app for this computer's
platform that a player runs without Ruby, with the gems its Gemfile.lock
locks; it needs Git and the network, and a C compiler for a gem whose
extension compiles.

On Linux, a game needs a desktop with X11 or Wayland and OpenGL, as a
LÖVE game does. On Windows, continuous integration draws on a software
renderer, and a game has also been played on a Windows PC with a GPU.
iPhone, iPad, and Android builds are experimental and built from source.
Lota binds every module of LÖVE's but love.thread, whose binding is
under way.

On another platform or Ruby, such as Alpine Linux, whose C library is
musl, RubyGems picks Lota's source gem, which stops and says so: Lota
has no build for those yet.
